# Teams / Helpdesk / Remote Support

把协作平台和 IT 支持社工当成正式 Initial Access。终点是 **remote interactive access / shell**，不是“用户回复了消息”。

---

## 1. 链

```text
External / cross-tenant Teams
→ IT/helpdesk impersonation
→ voice/callback 或聊天建立信任
→ Quick Assist / 合法 RMM / 远程支持
→ 操作者控制桌面
→ 本模块 COMPLETE（remote interactive = 本模块的 shell 等价物）
```

也可以叠 ClickFix：帮助台让用户“运行修复命令”。

---

## 2. 要点

```text
外租户 Teams 是否允许
helpdesk 常用工具：Quick Assist、TeamViewer、AnyDesk、公司 RMM
不要投明显恶意 exe；用他们自己的远程支持流程
一旦桌面到手：建稳定回调（仍本模块），再考虑 /post
```

---

## 3. 成功

```text
[+] 远程桌面/协助会话已建立
[+] 或用户已执行帮助台给出的命令并回连
```
